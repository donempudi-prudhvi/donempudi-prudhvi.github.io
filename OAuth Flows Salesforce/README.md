# Salesforce OAuth Flows

### This folder contains the OAuth 2.0  Flows implemented in pure HTML using Salesforce platform. This can be used to see how a particular OAuth flow is triggered and which params or payload is required for a particular OAuth flow. 

### The below OAuth flows are covered in this folder
1. Refresh Token Flow
2. Token Exchange Flow
3. User agent Flow
4. Web Server Flow
