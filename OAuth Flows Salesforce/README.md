# Salesforce OAuth Flows

### This folder contains the OAuth 2.0  Flows implemented in pure HTML using Salesforce platform. This can be used to see how a particular OAuth flow is triggered and which params or payload is required for a particular OAuth flow. 

### The below OAuth flows are covered in this folder
1. Refresh Token Flow [Refresh Token Flow](/OAuth%20Flows%20Salesforce/refreshtokenflow.html)
2. Token Exchange Flow [Token Exchange Flow](/OAuth%20Flows%20Salesforce/tokenexchnageflow.html)
3. User agent Flow [User Agent Flow](/OAuth%20Flows%20Salesforce/user-agent.html)
4. Web Server Flow [Web Server Flow](/OAuth%20Flows%20Salesforce/webserverflow.html)
